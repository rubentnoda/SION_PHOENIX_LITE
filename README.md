# SION PHOENIX LITE 🧠

**Cerebro de SION Fénix** - Configuración de GPT Personalizado

[![Version](https://img.shields.io/badge/version-1.0.0-blue.svg)](https://github.com/rubentnoda/SION_PHOENIX_LITE)
[![License](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)

## 📖 Descripción

SION PHOENIX LITE es una configuración completa para un GPT personalizado diseñado para servir como asistente inteligente en análisis, gestión de información y resolución de problemas.

Este repositorio contiene todo lo necesario para implementar y personalizar tu propio GPT basado en el "cerebro" de SION Fénix.

## 🚀 Inicio Rápido

1. **Clona este repositorio**
   ```bash
   git clone https://github.com/rubentnoda/SION_PHOENIX_LITE.git
   cd SION_PHOENIX_LITE
   ```

2. **Lee las instrucciones**
   - Revisa `instructions.md` para ver el comportamiento del GPT
   - Consulta `custom-gpt-config.json` para la configuración

3. **Configura tu GPT**
   - Sigue la guía detallada en [`USAGE.md`](USAGE.md)
   - Copia las instrucciones a tu GPT personalizado en ChatGPT
