# Knowledge Base

Este directorio contiene archivos de conocimiento adicional para SION PHOENIX LITE.

## Cómo agregar archivos

Puedes agregar aquí documentos, datos y recursos que el GPT personalizado debe tener en cuenta durante las conversaciones.

### Tipos de archivos recomendados:
- Documentos técnicos (.md, .txt, .pdf)
- Datos estructurados (.json, .csv)
- Guías y procedimientos
- Información de referencia específica del dominio

### Estructura sugerida:
```
knowledge_base/
├── technical/        # Documentación técnica
├── procedures/       # Procedimientos y guías
├── reference/        # Material de referencia
└── data/            # Datos estructurados
```

## Notas
- Mantén los archivos organizados y bien nombrados
- Documenta el propósito de cada archivo importante
- Actualiza esta guía cuando agregues nuevas categorías
